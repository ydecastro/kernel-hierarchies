# kernel-hierarchies

Code and figures for the paper

> Yohann De Castro, **Kernel Hierarchies for Global Optimisation**, preprint, 2026.

The paper lifts the moment–sum-of-squares (Lasserre) hierarchy from the monomial basis to a nested family of reproducing kernel Hilbert spaces generated by partial Taylor truncations of a universal kernel (the Gaussian as the guiding example), with kernel mean embeddings in the role of moments. This repository contains the Jupyter notebooks that produce every figure and every number quoted in the paper, their stored outputs, and the figures.

Repository: <https://github.com/ydecastro/kernel-hierarchies>

## Layout

```
code/                          notebooks (outputs stored), requirements.txt
code/bench_rate_results/       cached certified brackets used by bench_rate.ipynb
code/gmm10_results/            stored results of the ten-dimensional mixture (fig_gmm10.ipynb, Figure 1)
code/blasso2d_sketch_results/  stored results of the planar sketched run (fig_blasso_2d_sketch.ipynb, Figure 4)
figs/                          the paper's figures (PDF), README.txt
figs/extra/                    further figures produced by the benchmark and robustness notebooks
```

## Running the notebooks

Tested with Python 3.13.3 and the versions listed in `code/requirements.txt`.

```bash
python -m pip install -r code/requirements.txt
python -m ipykernel install --user --name kme-sos
cd code
jupyter nbconvert --to notebook --execute --inplace fig_blasso_2dgmm.ipynb
```

Most notebooks were run with a Jupyter kernel named `kme-sos`, which `Kernel-Hierarchies.ipynb` also uses with `RUN_FULL = True`; the second line registers the current environment under that name. Execute the notebooks from `code/`: they write the paper's figures to `../figs/` and the other figures to `../figs/extra/`. All random draws use fixed seeds. Solver statuses (for instance `optimal_inaccurate`, or Clarabel failures followed by an SCS fallback) can depend on the versions of cvxpy, Clarabel and SCS; the notebooks print them.

Flags at the top of some notebooks:

- `Kernel-Hierarchies.ipynb`: `RUN_FULL = True` re-executes the other notebooks on copies in a temporary directory; `WRITE_FIGS = True` also copies their figures into `figs/`.
- `bench_rate.ipynb`: `RECOMPUTE = True` recomputes the cached brackets in `code/bench_rate_results/` instead of loading them.
- `robustness.ipynb`: `FULL = True` gives the 50-draw study stored in `robustness_full.ipynb`.

## Solvers

Most semidefinite programs are posed with CVXPY and solved with SCS at tolerance 1e-11, first in the monomial basis and, where SCS stops short of that tolerance, in the scaled basis x^α/√α! (a diagonal congruence, the same program); Clarabel is the last resort. `bench_comparison.ipynb` calls SCS (1e-11) and Clarabel directly, `fig_gmm10.ipynb` and `fig_blasso_2d_sketch.ipynb` call SCS at 1e-10; the robustness notebooks use the cascade of the figure notebooks. The high-order relaxations of `bench_rate.ipynb` and `bench_rate_check.ipynb` use their own interior-point solvers in orthogonal (Chebyshev, Legendre) bases, because monomial-basis solves lose accuracy at large relaxation orders.
